# Nuzzle website

Home, privacy policy and support pages, published to GitHub Pages by
`.github/workflows/pages.yml` whenever this folder changes, at
https://philipn1-sketch.github.io/Nuzzle. The app links to `/privacy` and `/support` from
`src/config.ts`; the App Store listing uses the same two links. Links between pages are relative,
so the site works under the repository's path.
