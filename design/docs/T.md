# T

All text in Nuzzle. Body style (17, weight 600, rounded font) in the theme's ink colour by default. Follows the phone's text size setting.

* `tone`: `ink` (default), `muted` (labels, secondary lines), `accent` (rose, Left), `peach` (Right), `onAccent` (text on a filled rose or peach surface).
* `style`: pass a type token for other sizes: `type.timer` 56, `type.answer` 44, `type.side` 30, `type.title` 21, `type.body` 17, `type.label` 15, `type.small` 13.

Words: short and kind, no exclamation marks, no dashes.
